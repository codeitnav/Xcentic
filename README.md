# Xcentic - Company Website

This is the official website for **Xcentic**, a modern and innovative company focused on delivering high-quality solutions. The site is built using **Next.js**, **Tailwind CSS**, and advanced visual tools like **Three.js** for an interactive and professional user experience.

## 🌐 Live Website

Visit here: [https://www.xcentic.com/](https://www.xcentic.com/)

## 🚀 Tech Stack

- **Framework:** Next.js 15.3.2
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **3D & Graphics:** Three.js, @react-three/fiber, drei, three-globe
- **UI Libraries:** Lucide React, Tabler Icons, Radix UI
- **Animations:** Motion
- **Theming:** next-themes
- **Email Services:** nodemailer, resend

## 📁 Features

- Dynamic 3D globe visualizations
- Responsive design and dark mode
- Modular and scalable component architecture
- Integrated contact form using Nodemailer & Resend
- Fully optimized for performance and SEO

## ⚙️ Scripts

```bash
# Run in development mode
npm run dev

# Build for production
npm run build

# Start the production server
npm start

# Run linter
npm run lint
```

## 📦 Installation

```bash
git clone https://github.com/codeitnav/Xcentic.git
cd Xcentic
npm install
npm run dev
```
